# CI-ключ подписи

`ci.jks` — **публичный** ключ подписи для сборок в GitHub Actions
(пароль `goldsrcmaker`, alias `goldsrc`). Он лежит в открытом репозитории
намеренно: это не секрет, а способ давать всем CI-сборкам **одну и ту же
подпись**, чтобы новые APK ставились поверх старых без удаления приложения
(как `fwgs.pfx` в репозитории Xash3D FWGS).

Для публикации в магазинах приложений (Google Play и т.п.) этот ключ нужно
заменить на собственный закрытый.
