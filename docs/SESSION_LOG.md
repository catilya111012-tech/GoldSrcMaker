нереально. Схема: свой дамп игры → автоматический перевод исполняемого кода в C
+ ручные правки → платформенный слой (ОС, GPU-шейдеры, звук, ввод) → сборка под
arm64 Android. Цена: месяцы на игру; проще брать игры с готовыми рекомп-тулзами.
Легально — та же серая зона: свои файлы, распространение сборок опасно.
